O **Lore Master** é uma plataforma analítica desenvolvida para estúdios e desenvolvedores de jogos independentes no ecossistema da **Steam**. Utilizando inteligência preditiva acionada pelo motor **Google Gemini AI**, o sistema transforma milhares de análises (reviews), dados demográficos e métricas de jogadores em diagnósticos acionáveis e recomendações técnicas práticas.
